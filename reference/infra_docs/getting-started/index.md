## Overview

The Shared Docker Infrastructure provides a unified platform for running AI services with:

- **Security First**: All external access through Traefik reverse proxy only
- **Centralized Management**: LiteLLM for inference, Orchestrator for resource management
- **Configurable**: All ports and settings managed via environment variables
- **Observability**: Built-in Langfuse integration for tracing and monitoring
