# Langfuse

Langfuse provides LLM observability, tracing, and evaluation for the infrastructure.

## Overview

- **Purpose:** LLM observability and tracing
- **Domain:** `langfuse.local`
- **Internal URL:** `http://langfuse:3000`
- **API:** `http://langfuse.local/api`
- **Auth:** API keys (generated by `setup-secrets`)

## Key Features

- ✅ **Automatic tracing** - LiteLLM integration
- ✅ **Session tracking** - User and session management
- ✅ **Prompt management** - Version-controlled prompts
- ✅ **Evaluation** - Scoring and feedback
- ✅ **Analytics** - Usage metrics and insights
- ✅ **Error tracking** - Failure analysis

## Quick Start

```bash
# Start Langfuse
make up-langfuse

# Or using Docker Compose
docker compose -f docker-compose.langfuse.yml up -d

# Access UI
open http://langfuse.local

# Check health
curl http://langfuse.local/api/health
```

### Get API Keys

1. Open http://langfuse.local
2. Log in with credentials from `langfuse/.env`
3. Go to Settings > API Keys
4. Copy **Public Key** and **Secret Key**

## Usage

### Automatic Tracing (LiteLLM)

All LiteLLM calls are automatically traced when configured:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://litellm.local/v1",
    api_key="sk-litellm-master"
)

# This call is automatically traced
response = client.chat.completions.create(
    model="qwen-35-27",
    messages=[{"role": "user", "content": "Hello!"}],
    metadata={
        "user_id": "user-123",
        "session_id": "session-456"
    }
)

# View trace at http://langfuse.local
```

### Manual Tracing (Python SDK)

```python
from langfuse import Langfuse

langfuse = Langfuse(
    public_key="pk-lf-...",
    secret_key="sk-lf-...",
    host="http://langfuse.local"
)

# Create trace
trace = langfuse.trace(
    name="chat-completion",
    user_id="user-123",
    session_id="session-456",
    metadata={"environment": "production"}
)

# Add generation
generation = trace.generation(
    name="response",
    model="qwen-35-27",
    input=[{"role": "user", "content": "Hello!"}],
    output="Hi there! How can I help you?",
    model_parameters={"temperature": 0.7}
)

# Add score
trace.score(
    name="helpfulness",
    value=0.9,
    comment="Very helpful response"
)

# Flush traces
langfuse.flush()
```

### With Decorators

```python
from langfuse.decorators import observe, langfuse_context

@observe()
def generate_response(query: str) -> str:
    """Generate response with automatic tracing."""
    # This function is automatically traced
    response = client.chat.completions.create(
        model="qwen-35-27",
        messages=[{"role": "user", "content": query}]
    )
    return response.choices[0].message.content

@observe()
def pipeline(audio_file: str) -> dict:
    """Multi-step pipeline with tracing."""
    # ASR
    with open(audio_file, "rb") as f:
        transcript = client.audio.transcriptions.create(
            model="distil-whisper",
            file=f
        )
    
    # LLM processing
    summary = generate_response(f"Summarize: {transcript.text}")
    
    # TTS
    audio = client.audio.speech.create(
        model="kokoro",
        input=summary
    )
    
    return {
        "transcript": transcript.text,
        "summary": summary,
        "audio": audio.content
    }

# Usage
result = pipeline("meeting.mp3")

# Get trace URL
trace_url = langfuse_context.get_current_trace_url()
print(f"View trace: {trace_url}")
```

### LangChain Integration

```python
from langfuse import get_client
from langfuse.langchain import CallbackHandler
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

# Set up Langfuse
langfuse = get_client()
langfuse_handler = CallbackHandler()

# Create chain
llm = ChatOpenAI(
    base_url="http://litellm.local/v1",
    api_key="sk-litellm-master",
    model="qwen-35-27"
)

prompt = ChatPromptTemplate.from_template("Answer: {question}")
chain = prompt | llm

# Invoke with tracing
response = chain.invoke(
    {"question": "What is machine learning?"},
    config={"callbacks": [langfuse_handler]}
)

# Flush traces
langfuse.flush()
```

### LiteLLM SDK Integration

```python
import litellm

# Enable Langfuse callbacks
litellm.success_callback = ["langfuse"]
litellm.failure_callback = ["langfuse"]

# Make completion (automatically traced)
response = litellm.completion(
    model="openai/qwen-35-27",
    api_base="http://litellm.local/v1",
    api_key="sk-litellm-master",
    messages=[{"role": "user", "content": "Hello!"}],
    metadata={
        "user_id": "user-123",
        "session_id": "session-456",
        "tags": ["production", "chatbot"]
    }
)
```

### Prompt Management

```python
# Create managed prompt
langfuse.create_prompt(
    name="summarize-prompt",
    prompt="Summarize the following text concisely:\n\n{{text}}",
    config={"model": "qwen-35-27", "temperature": 0.3}
)

# Use managed prompt
prompt = langfuse.get_prompt("summarize-prompt")
compiled = prompt.compile(text="Long text to summarize...")

response = client.chat.completions.create(
    model=prompt.config.get("model", "qwen-35-27"),
    messages=[{"role": "user", "content": compiled}],
    temperature=prompt.config.get("temperature", 0.7)
)
```

### Evaluation & Scoring

```python
# Add scores to traces
trace.score(
    name="helpfulness",
    value=0.9,  # 0-1 scale
    comment="Very helpful"
)

trace.score(
    name="accuracy",
    value=1.0,
    comment="Factually correct"
)

trace.score(
    name="toxicity",
    value=0.0,  # Lower is better
    comment="No toxic content"
)
```

## Troubleshooting

### Traces Not Appearing

```bash
# Check environment variables
echo $LANGFUSE_PUBLIC_KEY
echo $LANGFUSE_SECRET_KEY

# Verify Langfuse is running
curl http://langfuse.local/api/health

# Check LiteLLM config
cat litellm/config.yaml | grep -A 5 langfuse

# Test connection
curl http://langfuse.local/api/health \
  -u "pk-lf-...:sk-lf-..."
```

### Authentication Errors

```bash
# Regenerate keys
make setup-secrets

# Update environment
docker compose restart langfuse
docker compose restart litellm
```

