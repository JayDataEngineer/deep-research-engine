# AUTO STUDIO Extension

## Overview

AUTO STUDIO is an automated multi-modal content generation system that produces video podcasts from scripts. It integrates multiple AI models (Deep Agent, Qwen Image Edit, LTX-2, IndexTTS) into a unified pipeline.

---

## LTX-2 Model Capabilities

**LTX-2 is a versatile set of models** with unique flexibility:

| Input | Output | Use Case |
|-------|--------|----------|
| **Image + Text** | **Video + Audio** | Video generation from start frame |
| **Video + Audio** | **Video** | Lipsync + Upscaling (temporal + spatial) |

### Key Difference from Other Models
- Most video models: Image → Video only
- **LTX-2**: Can output BOTH video AND audio
- Audio dialogue must be **explicitly written in the prompt** (quoted text)
- Supports **lipsync refinement** via upscaling pass

---

## Two Generation Modes

AUTO STUDIO has two modes with different quality/latency tradeoffs:

### Fast Mode
**Lower latency, good quality**
- Image → Video + Audio (single LTX-2 pass)
- Audio is generated by LTX-2 (prompt must include spoken dialogue)

### Quality Mode
**Higher latency, best quality**
- Fast Mode → Video + AI Audio
- IndexTTS Voice → Professional TTS
- Video + Audio → Video (LTX-2 lipsync + upscaling pass)

## Pipeline Flow

### Common Steps (Both Modes)

#### Step A: Deep Agent Planning
**Input:** Script + reference images + visual descriptions

```yaml
Example context:
  script: "Podcast dialogue markdown"
  base_scene: "STUDIO.png (wide shot with Emma + Olivia)"
  speaker_images:
    - "Emma.png (bubbly blonde woman)"
    - "Olivia.png (anime goth woman)"
  visual_descriptions:
    Emma: "bubbly blonde with warm expressions"
    Olivia: "goth aesthetic with dark hair and makeup"
```

**Deep Agent Output (Pydantic validated with retries):**
```json
{
  "clips": [
    {
      "clip_id": "clip_001",
      "qwen_image_to_edit": "STUDIO.png",
      "qwen_edit_prompt": "Zoom in on Emma from the base studio scene...",
      "ltx2_prompt": "The shot opens on Emma (bubbly blonde) speaking warmly. 'Welcome back to the show!' she says with genuine enthusiasm...",
      "emotion_vectors": {"Emma": {"happy": 0.8, ...}},
      "duration_frames": 120
    }
  ]
}
```

**Key Parameters:**
- `qwen_image_to_edit`: Which base image to modify (STUDIO.png, Emma.png, Olivia.png)
- `qwen_edit_prompt`: Qwen Image Edit instruction
- `ltx2_prompt`: LTX-2 prompt **with quoted dialogue** for audio generation
- `emotion_vectors`: For IndexTTS (Quality Mode only)

#### Step B: Qwen Image Edit
**Input:** Base image + edit prompt

```python
# Multi-image text-referencing
image1 = "STUDIO.png"      # Background + composition
image2 = "Emma.png"        # Emma's identity
image3 = "Olivia.png"      # Olivia's identity

prompt = """
Maintain the podcast studio background from image 1.
The host on the left is the bubbly blonde woman from image 2.
The guest on the right is the goth woman from image 3.
Both are engaged in friendly conversation with warm expressions.
"""
```

**Output:** Start frame for each clip

#### Step C: LTX-2 Video Generation (Image → Video + Audio)
**Input:** Start frame + prompt with quoted dialogue

```python
ltx2_prompt = """
The shot opens on Emma (bubbly blonde, warm smile). She leans forward slightly.
"Welcome back to the show!" she says with genuine enthusiasm,
her eyes bright as she looks toward the guest.
"""

# Note: Dialogue in quotes generates audio
```

**Output:** Video clip + AI-generated audio

### Quality Mode (Additional Pass)

#### Step E: IndexTTS Voice Generation
**Input:** Dialogue lines + emotion vectors + voice references

```python
dialogue_lines = [
    {
        "speaker": "Emma",
        "text": "Welcome back to the show!",
        "emotion_vectors": {
            "happy": 0.8,
            "surprised": 0.2,
            "intensity": 0.5
        }
    }
]

voice_references = {
    "Emma": "/path/to/emma_voice_reference.wav",
    "Olivia": "/path/to/olivia_voice_reference.wav"
}
```

**Output:** Professional TTS audio with emotion

#### Step F: LTX-2 Lipsync + Upscaling
**Input:** Fast Mode Video + IndexTTS Audio

```python
# LTX-2 upscaling mode
# - Temporal upscaling: Smoother motion
# - Spatial upscaling: Higher resolution
# - Lipsync refinement: Match mouth movements to new audio
```

**Output:** Final video with professional audio and perfect lipsync

#### Step G: Final Stitching
```bash
# Combine all clips
ffmpeg -f concat -i concat_list.txt \
  -c:v libx264 -crf 23 -preset medium \
  -c:a aac \
  -shortest \
  final_quality.mp4
```

## Key Constraints & Best Practices

### LTX-2 Prompting
1. **Audio dialogue must be in quotes**
   ```python
   # ✅ Correct
   "Hello everyone!" she says warmly.

   # ❌ Wrong
   She greets the audience.
   ```

2. **Use present tense**
   ```python
   # ✅ Correct
   Emma smiles and leans forward.

   # ❌ Wrong
   Emma smiled and leaned forward.
   ```

3. **Describe physical cues, not emotions**
   ```python
   # ✅ Correct
   Her eyes crinkle at the corners, mouth curving upward.

   # ❌ Wrong
   She feels happy.
   ```

### Qwen Image Edit Multi-Image
1. **Always reference images by number**
   ```python
   "Maintain the background from image 1."
   "The person on the left is from image 2."
   ```

2. **Spatial positioning is critical**
   ```python
   # Specify LEFT/RIGHT explicitly
   "from image 2 on the LEFT"
   "from image 3 on the RIGHT"
   ```

3. **Identity preservation phrases**
   ```python
   "Keep face features exactly as shown in image 2."
   "Do not blend or morph the identities."
   ```

## Architecture Decisions

### Why Two Modes?
- **Fast Mode**: Preview drafts, rapid iteration
- **Quality Mode**: Final production output

### Why Audio First (Quality Mode)?
- Audio timing determines video clip duration
- Lipsync requires audio reference
- Enables accurate synchronization

### Why Multi-Image Qwen Edit?
- Single base scene → visual consistency
- Individual speaker references → identity preservation
- Text-referencing → precise control

## Troubleshooting

### LTX-2 Not Generating Audio
- Check that dialogue is **in quotes** in the prompt
- Verify prompt format: `"Spoken text" speaker says...`

### Qwen Edit Face Bleeding
- Add explicit: "Keep face features EXACTLY as Image X"
- Check resolution (1024x1024 recommended)
- Simplify edit request

### Lipsync Misalignment
- Verify audio timing matches clip duration
- Check IndexTTS output duration
- Ensure LTX-2 upscaling mode is enabled
