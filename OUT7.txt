│ Plan: Migrate Deep Research Engine to LangGraph Patterns                     │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ The deep-research-engine currently uses a manual phase loop instead of       │
│ proper LangGraph StateGraph. This means we're missing:                       │
│ - Automatic state persistence with checkpointing                             │
│ - Built-in vectorization via LangGraph Store                                 │
│ - Parallel worker execution with Send                                        │
│ - Clean routing with Command                                                 │
│ - Resume from failure capability                                             │
│                                                                              │
│ This migration adds these features while maintaining backward compatibility. │
│                                                                              │
│ ---                                                                          │
│ Architecture Changes                                                         │
│                                                                              │
│ Current (Manual Loop)                                                        │
│                                                                              │
│ engine.py → while loop → phases executed sequentially                        │
│            ↓                                                                 │
│      ingestion → drafter → critic → neo4j_builder → synthesizer              │
│                                                                              │
│ New (StateGraph)                                                             │
│                                                                              │
│ engine.py → StateGraph.compile(checkpointer, store)                          │
│            ↓                                                                 │
│      START → ingestion → drafter → critic ⇄ drafter (retry)                  │
│                               ↓                                              │
│                         neo4j_builder → synthesizer → END                    │
│                                                                              │
│ ---                                                                          │
│ Implementation Steps                                                         │
