## What is Deep Research Engine?

Deep Research Engine is a high-performance orchestration framework for:

- **Multi-agent intelligence** - Coordinate multiple AI agents for complex research tasks
- **Vector search** - Semantic memory and knowledge retrieval
- **Recursive knowledge synthesis** - Iterative refinement and quality assurance
- **Multimodal processing** - Handle text, PDFs, audio, video, and images

## Architecture Overview

```
Config (YAML) → Engine → Ingestion → Drafter ↔ Critic → Neo4j → Synthesis
```

The engine uses a 5-node pipeline:

1. **Ingestion** - Extract text from various sources (PDFs, audio, video, web)
2. **Drafter** - Plan and execute research tasks with sub-agents
3. **Critic** - Quality assurance and revision loop
4. **Neo4j Builder** - Optional knowledge graph construction
5. **Synthesis** - Generate final reports and outputs

## Prerequisites

- Python 3.11+
- Docker (for infrastructure services)
- Access to LLM providers (via LiteLLM)
