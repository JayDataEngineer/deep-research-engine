# Multimodal Ingestion & Identity Resolution Pipeline Summary

## Overview
This document summarizes the implementation of the phased, batch-oriented ingestion pipeline for the `deep-research-engine`. The architecture is optimized for hardware-constrained environments (single-GPU) by transitioning from serial processing to a memory-managed, phased execution model.

## Implementation Status: ✅ Complete

### Phase 1: Temporal Normalization
- **Logic**: Integrated `pytz` for rigorous chronological baseline establishment.
- **Handling**: All timestamps are normalized to `America/New_York` with full support for Daylight Saving Time (DST) transitions, avoiding synchronization errors during media stitching.
- **Formats**: Supports both Telegram `messages.html` and `result.json` export formats.

### Phase 2: Visual Processing & Spatial Identity Clustering
- **Scene Detection**: Implemented FFmpeg-based scene detection using the Sum of Absolute Differences (SAD) metric to extract only visually distinct frames.
- **Identity Resolution**: Utilized **DBSCAN** clustering with **Cosine Similarity** on 512-dimensional facial embeddings to assign consistent identity tags (`Identity_Cluster_N`) across photos and video frames without prior subject knowledge.

### Phase 3: Acoustic Mega-File Strategy
- **Concatenation**: Audio fragments (voice notes, video audio) are chronologically concatenated into contiguous "Mega-Files" (up to 60 minutes) to solve the "Cross-File Diarization Problem."
- **Boundary Mapping**: A deterministic JSON Boundary Map tracks the exact start/end offsets of original files within the Mega-File, allowing perfect "un-stitching" of transcripts.

### Phase 4: GPU Memory Management
- **Lifecycle Hooks**: Implemented a strict `purge_vram()` sequence:
    1. `del model, tensor` (Variable dereferencing)
    2. `gc.collect()` (Python garbage collection)
    3. `torch.cuda.empty_cache()` (PyTorch allocator reset)
- **Benefit**: Eliminates CUDA Out-of-Memory (OOM) errors when switching between VLM/Face models and the large VibeVoice ASR-7B model.

### Phase 5: Acoustic Diarization & Clustering
- **ASR**: Integrated **VibeVoice ASR-7B** for single-pass transcription and diarization with a 64K token context window.
- **Cross-Pass Verification**: Added utility hooks for **ECAPA-TDNN** (SpeechBrain) to generate 192-dimensional biometric voiceprints for reconciling identities across multiple Mega-Files.

### Phase 6: Multimodal Synthesis
- **Normalization**: The pipeline yields a high-fidelity "Big Text Dump" where Generic IDs are mapped to deductive identities (e.g., `Speaker 0` + `Cluster 1` -> `David`).
- **Enrichment**: The final output is a pristine, human-readable Markdown corpus enriched with named entities, visual descriptions, and precise local timecodes.

## Technical Stack
- **Languages/Frameworks**: Python 3.12, PyTorch, LangGraph
- **Media Tools**: FFmpeg 6.1, OpenCV
- **ML Libraries**: scikit-learn (DBSCAN), SpeechBrain (ECAPA-TDNN), Beautiful Soup 4 (HTML Parsing)
- **Models**: VibeVoice ASR-7B, InsightFace/CompreFace (Embeddings)

## File Manifest
- `src/deep_research_engine/utils/pipeline.py`: Core pipeline logic (Normalization, Mega-Files, Clustering, VRAM Purge).
- `src/deep_research_engine/nodes/ingestion.py`: Orchestration of the phased ingestion node.
- `src/deep_research_engine/utils/multimodal.py`: Enhanced ASR and Face utility functions.
